# Web-Tech-Mini-Projects
## 📝 To-Do List

A feature-rich To-Do List web application built using **HTML, CSS, and JavaScript**. This project helps users organize and manage their daily tasks easily.

### 🚀 Features

* ➕ **Add Tasks** — Add new tasks to your to-do list.
* ✏️ **Edit Tasks** — Update or modify existing tasks.
* 🗑️ **Delete Tasks** — Remove tasks that are no longer needed.
* 🔍 **Search Tasks** — Search for a specific task quickly.
* 🔽 **Filter Tasks** — Filter tasks based on their status or priority.
* 🧹 **Clear Tasks** — Clear tasks from the list.
* 🌙 **Dark Mode** — Switch between light mode and dark mode.
* ⭐ **Task Priority** — Set priorities for tasks to help organize important work.
* ✅ **Task Management** — Mark tasks as completed and keep track of pending tasks.

### 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
  
### 📚 Concepts Practiced

* DOM Manipulation
* JavaScript Functions
* Arrays
* Event Handling
* Conditional Statements
* Loops
* Local Storage
* Search and Filter Logic
* CRUD Operations
* Dark Mode using JavaScript and CSS
